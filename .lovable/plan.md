Цей план — покрокова інструкція, як отримати всі файли проєкту (TypeScript, React, стилі, ассети, конфігурацію) в одну папку на ноутбуці.

## Спосіб: GitHub → Download ZIP (підходить, щоб не ставити git)

1. Підключити GitHub у Lovable
   - У редакторі Lovable натиснути **Plus (+)** у чат-інпуті (знизу зліва) → **GitHub** → **Connect project**.
   - Авторизувати Lovable на GitHub і вибрати свій акаунт/організацію.
   - Створити репозиторій — Lovable сам запише туди весь актуальний код.

2. Завантажити ZIP з GitHub
   - Відкрити створений репозиторій на github.com.
   - Натиснути зелену кнопку **Code** → **Download ZIP**.
   - Зберегти архів на ноутбук.

3. Розпакувати в одну папку
   - Подвійний клік по ZIP або розпакувати через системний архіватор.
   - Вийде одна папка з усім проєктом: `src/`, `public/`, `package.json`, `vite.config.ts`, `README.md`, зображення тощо.

4. Альтернатива (якщо платний тариф)
   - У **Code Editor** (де ти зараз) прокрутити файл-дерево зліва до низу і натиснути **Download codebase**, якщо кнопка є.
   - Це одразу дасть ZIP з усім кодом без GitHub.

5. Щоб запустити локально (опціонально)
   - Відкрити термінал у папці проєкту.
   - Виконати:
     ```
     npm install
     npm run dev
     ```
   - Сайт відкриється за адресою `http://localhost:8080`.

## Результат
На ноутбуці буде повна папка з проєктом: всі `.ts`, `.tsx`, `.css`, `.json`, `.jpg` та інші файли.
